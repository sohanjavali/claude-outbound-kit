# Angles

An angle is the reason a message connects their situation to the offer. The selector picks one per message and spreads them across each batch, and the weekly report shows which ones get replies. Keep names short and stable.

| Angle | When to use it | The connection, in one line | The guess it leads to |
|---|---|---|---|
| [e.g. time-back] | [owner doing their own selling] | [they get hours back each week] | [quotes go quiet because nobody has time to chase them] |
| [e.g. growth-moment] | [new location, new hire, new service] | [more capacity means more leads to work] | [follow-up hasn't grown with the business] |
| [angle] | [when] | [connection] | [guess] |

Write the "when" and "connection" columns as notes, not message copy. The writer never sees this file, and ready-made openers lead to identical messages.
